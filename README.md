# ATS Score Detector Pro

A modern web app for resume ATS scoring, optimization, benchmarking, and job tracking.

## Features
- AI-driven ATS score (0-100) with clear score ring and weighted breakdown.
- Missing keyword + skill gap detection from any pasted job description.
- Ranked optimization recommendations by impact.
- Resume tailoring and cover letter generation with ATS-friendly templates.
- Job submission tracker with local analytics dashboard and score trend chart.
- Benchmark table comparing relative outcomes versus common ATS tools.
- Optional LinkedIn text input for profile consistency suggestions.

## Run locally
Open `index.html` directly in your browser.
